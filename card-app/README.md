# 解压捏捏乐 · 产品需求文档

一个跑在抖音信息流里的轻量解压产品：兴趣卡本体可玩（长按捏爆脆皮捏捏），兴趣卡落地页承接解压报告与玩法矩阵，两级结构共享同一份累计账本。

上线 13 个自然日（2026-11-13 ~ 2026-11-25，平台 T+1 口径）数据速览：

| 指标 | 数值 |
| --- | --- |
| 累计访问量 PV | 588,395 |
| 单日 PV / UV 峰值 | 494,641 / 429,612（11-25） |
| 秒开率 | 30.7% → 92.0%（首日 → 11-24） |
| 首屏耗时 LCP P99 | 4,923ms → 1,369ms |

> 本文档是产品的需求基线：背景、目标、范围、流程、规则、验收与埋点写清楚「做什么、不做什么、为什么」。规则变更先改这里，再动实现。

---

## 一、需求背景

**来源。** 情绪解压是信息流内容里的稳定垂类：捏捏乐开箱、ASMR、切香皂这类视频长期有稳定消费量，评论区高频出现「看着就解压」「我也想捏一个」。用户的意愿是明确的，缺的不是内容，而是一个能立刻上手的「亲手捏」的入口。

**现状的三个问题：**

1. 解压内容以「看」为主，情绪释放靠代入，延迟且浅——看到不等于摸到；
2. 真正可「玩」的解压产品（App、小游戏合集）入口深、要下载注册，与解压场景的即时性相悖。压力峰值往往出现在通勤、工间、睡前的几分钟碎片里，用户没有耐心走完一条下载链路；
3. 既有轻互动反馈太薄：点一下弹一下，捏完什么都不留下，情绪没有「释放完了」的出口感。

**为什么做。** 兴趣卡形态把可玩的部分前置到信息流本体：刷到即可玩，零下载、零注册，30 秒内完成一次完整的释放闭环。卡片与落地页的两级结构天然匹配这个场景——卡片承担即时爽感，落地页承接积累与延伸，用户不需要做任何「进入成本」的决策。

## 二、需求目标

**用户价值（不只写做什么）：**

- 3 秒理解玩法，第一次长按就获得真实反馈，零学习成本；
- 30 秒内完成「理解 → 操作 → 反馈 → 结果」的完整闭环，产生「这一口的压力释放完了」的完成感；
- 累计解压值让每次把玩都算数——情绪释放被记录、被延续，而不是一次性的。

**业务价值：**

- 验证「卡片即产品」的形态假设：卡片本体可以承载核心体验，而不是只充当落地页的广告位；
- 沉淀可复用的解压产品资产（玩法矩阵、五档等级体系、报告页结构），切香皂已验证横向扩品类的路径走得通。

**数据指标：**

| 指标线 | 指标 | 目标 |
| --- | --- | --- |
| 体验 | 秒开率 | ≥ 90%（上线后实测 92.0%，见第七节） |
| 体验 | 首屏耗时 LCP P99 | ≤ 1.5s（实测 1,369ms） |
| 参与 | 人均捏捏次数 / 捏爆达成率 | 口径见第九节埋点 |
| 参与 | 次均时长 | 碎片场景，只做监控不设考核——追求时长反而伤害体验 |
| 质量 | 峰值日能力调用失败影响设备占比 | ≤ 1%（实测 0.7%） |

## 三、需求范围

**本期做：**

- 兴趣卡本体：脆皮捏捏（长按捏压、力度三档、捏爆两段时序）、DIY 自定义、叠捏 1–100、ASMR 火炉背景音、3D 书桌场景；
- 兴趣卡落地页：解压报告（五档压力等级）、累计统计、小游戏馆（捏泡泡纸、疯狂解压按钮、切香皂）；
- 状态互通：解压值在卡片、落地页与多次进入之间累计一致。

**明确不做（边界与理由）：**

- 不做社交：无排行、无分享互动闭环、无 UGC。解压是向内的情绪行为，比较与围观都在制造焦虑，方向与产品目标相反；
- 不做账号体系：不注册、不登录，数据按设备与卡片身份维度统计，多设备间不合并；
- 不做付费与广告；
- 不做多语言与深色模式；
- 卡片上不做任何需要「教学」才能玩的机制；
- 不引入实时物理引擎：捏爆形变与切香皂皂屑都是按约定动作设计的动画帧——用一点真实感上的保守，换低端机不掉帧。

## 四、用户角色

| 角色 | 权限 | 边界说明 |
| --- | --- | --- |
| C 端用户 | 全部玩法、DIY、叠捏、小游戏馆；解压值按卡片身份累计 | 无游客/会员分层，权限全员一致；无需任何注册与授权动作 |
| 创作者（维护者） | 只读：运行数据（访问量、性能、异常）、业务统计（解压值、次数、最高力度） | 经平台数据工具查看；产品内不提供管理后台，不可修改用户数据 |
| 平台 | 卡片分发、宿主能力（落地页入口按钮、背景音乐播放）、审核 | 分发策略与宿主表现不可控，产品边界止于卡片与落地页内部 |

补充边界：产品不申请通讯录、位置、相册等任何敏感权限；音频播放遵循系统静音开关、不做绕过——解压不扰民。

## 五、业务流程

**主流程（用户视角）：**

1. 信息流刷到卡片：3D 书桌场景 + 捏捏本体，宿主标题一句话说明玩法；
2. 长按球体任意位置：接触点出现局部凹陷与阴影，力度条随按住时长上升，音效档位跟随切换；
3. 力度至 60%：裂纹出现、爆浆开始渗出；≥ 70% 松手即捏爆——蜡皮碎裂、内馅涌出、残体留在台面；
4. 解压值入账（力度档 × 叠捏数量倍率），按节流规则上报；
5. 经宿主入口进入落地页：报告首屏直接从压力等级开始（五档之一 + 解释 + 建议），无过渡话术；
6. 小游戏馆继续消费：捏泡泡纸 / 疯狂解压按钮 / 切香皂；
7. 回到信息流再刷到卡片：解压值与统计接续，捏捏状态可经「再捏一次」复原重玩。

**关键业务规则（研发与测试不需要自行猜测的部分）：**

- **R1 力度档位**：< 35 轻捏，纯内馅湿陷音；35–70 用力捏，蜡皮脆裂 + 湿陷叠加；≥ 70 判定捏爆，蜡壳崩裂 + 大口湿陷。爆浆自 60% 起渗出。
- **R2 捏爆后行为**：残体保留，单调塌陷、无回弹、无弹性过冲；「再捏一次」复原全新蜡皮，解压值与全部统计不重置。
- **R3 DIY**：预设形象为蜜桃团子、可可方包、芝士角角，支持拼装组合不同形状与大小，可选颜色与内馅，实时预览、确认后生效；DIY 内部不提供层数设置。
- **R4 叠捏**：数量范围 1–100，左右加减调整；数量为 1 时正视近圆大球，> 1 切换为侧视压扁椭圆垂直堆叠成塔；调整数量时捏捏自动复原全新蜡皮状态，累计统计保留。
- **R5 解压值口径**：按力度档位 × 叠捏数量倍率累计；最高力度记录历史极值档位（如「捏爆」）。
- **R6 音效播放**：每次播放独立创建音频实例、播完即销毁回收；遵循系统静音开关；播放失败静默降级，不阻塞任何视觉反馈。
- **R7 上报与接续**：解压值增量按 400ms 节流窗口上报；卡片隐藏/卸载瞬间兜底上报未同步增量；进入卡片或落地页时回读服务端累计值接续展示。
- **R8 换装**：切换玩具或颜色，全部累计统计保留。

**异常流程：**

| 场景 | 现象 | 产品行为 |
| --- | --- | --- |
| 弱网进入 | 累计值回读慢 | 卡内先以本地态可玩，回读完成后接续展示；核心体验（捏压 + 视觉反馈）不依赖网络 |
| 上报请求失败 | 增量暂时未同步 | 不阻塞交互；恢复后随下一节流窗口补报 |
| 进程在节流窗口内被杀 | 最后一段增量未报 | 可能丢失 400ms 内增量，接受该损耗：解压值不是资金属性数据，不值得为它做持久化重试队列 |
| 音频加载失败 / 域名未配置 | 无声 | 静默降级，玩法与视觉完全不受影响（遗留项见第十节） |
| 系统静音开关开启 | 外放无声 | 遵循开关，不绕过 |
| 卡槽高度 300 / 436 两档 | 卡片尺寸不同 | DIY 弹层挂载点上移至卡片根节点，所有行高锁定 px 并预留 ≥ 10% 冗余，防真机字体膨胀导致文字溢出堆叠 |

## 六、功能需求

### 6.1 兴趣卡（卡片本体）

**场景**：3D 渲染书桌场景——暖色墙面、台灯光晕、木色桌面、墙面搁板与装饰摆件，全卡透出氛围背景。

**捏捏本体**：任意颜色的捏捏外层覆盖白色半透乳白蜡壳，蜡皮带大豆蜡冷凝后的哑光粉霜颗粒质感。

**长按捏压**：凹陷仅出现在接触位置并带阴影，球体整体不完全压扁；松手后保留陶土指印记忆。

**捏爆两段时序**：蜡皮先碎裂（捏爆前完全不可见内馅）→ 内馅涌出、摊开、沿球面下淌。下坠全程保持圆润形态。明确禁止：生硬长条状滴落、竖直浆柱、拉丝吊坠、弹性回弹过冲——这些形态在真实高黏度浓浆上不成立。

**底部操作区**：「DIY 捏捏」与「再捏一次」并排，随时可点，不设层级入口。

**音效（三通道）**：蜡皮脆裂 / 蜡壳崩裂 / 内馅湿陷三个独立通道，按 R1 档位组合播放；能量集中落在 1.5–3kHz 人耳敏感频段，响度按宿主背景音乐的掩蔽效应校准，手机扬声器外放场景各档位清晰可闻；叠捏时随数量密集连播（间隔 40–90ms、播放速率缓升封顶 2.2），超过采样上限按比例抽样，杜绝百只连捏的音频风暴。

**背景音乐**：ASMR 火炉声 lo-fi 版。约束：0 秒即出黑胶沙沙底噪（无开头静音）、中频突出落在手机扬声器高效发声区、体积压缩至 1M 以内、循环无缝、响度符合流媒体标准。

### 6.2 兴趣卡落地页

**报告首屏**：直接从压力等级开始，不设「数据已同步」类提示话术。等级由累计解压值落档：

| 累计解压值 | 等级 |
| --- | --- |
| 1 – 49 | 🧸 初来乍到 |
| 50 – 149 | 🫧 入门捏捏生 |
| 150 – 399 | 💪 熟练解压手 |
| 400 – 999 | 🎯 资深捏捏家 |
| 1000+ | 🏆 解压狂人 |

每档配专属标识、俏皮解释与一条解压建议（示例：「入门捏捏生——刚上手不久，累计五十点解压值入袋。捏捏乐的新手村大门已经为你敞开。」）。

**统计区**：累计解压值、捏捏次数、最高力度三项。

**玩法提示位**：「长按不松手可以攒大力，力度条拉满试试『捏爆』的爽感」——轻教学，替代说明书。

**小游戏馆**（三个入口，均在本页内闭环）：

| 入口 | 一句话钩子 |
| --- | --- |
| 🫧 捏泡泡纸 | 一排排捏爆泡泡，听啵啵声 |
| 🔴 疯狂解压按钮 | 连按充能，满格爆发彩带 |
| 🧼 切香皂 | 一刀一刀切出光洁切面 |

**尾部回访位**：「想再捏一次？回到信息流就能找到捏捏乐」。

### 6.3 切香皂（规则级展开）

主循环：点「切一刀」→ 小刀从左向右扫过香皂顶面（0.62s，带切入下压动作）→ 切面高光闪过 → 每刀 7 粒皂屑按左飘/直落/右飘三向、三档尺寸崩落，散落台面停留后渐隐（单屑动画 1.6s）→ 一片皂片坠落到台面留存 → 香皂变薄、剩余百分比更新。

- **完成判定**：6 刀切完，等待切屑落定（约 1s）后展示切面评分（80–95 分）与「换一块新的」；
- **换新**：随机切换口味（薄荷牛奶 / 奶油桃桃 / 海盐柠檬），台面皂片与切屑全量清空、刀数归零；
- **防误触**：切割动画期间按钮置灰显示「咔嚓…」，禁止重复点击；
- **音效**：两版切皂声（离散颗粒崩解脉冲合成，含切入脆响与皂屑崩落声），主版 75% / 备版 25% 随机，单次变速 0.94–1.08 消除连切重复感；每次播放独立实例、播完销毁。

### 6.4 状态互通

卡片是唯一写入端（捏压产生增量），落地页是展示与消费端。互通三原则：进卡回读接续（R7）、增量节流上报、隐藏兜底。落地页首屏等级永远反映卡上最新累计，用户不重复操作、不重复攒值。

## 七、非功能需求

**性能（上线 13 个自然日实测）：**

| 指标 | 上线初期 | 中段高点 | 当前 |
| --- | --- | --- | --- |
| 秒开率 | 30.7%（11-13） | 53.3%（11-19） | 92.0%（11-24），峰值日 90.7% |
| LCP P99 | 4,923ms | 25,165ms（11-19） | 1,369ms（11-25） |

优化路径：背景音乐压缩至 1M 内并去掉开头静音、启动资源瘦身与按需加载、音效流式分段加载。峰值抗压：单日 494,641 PV 下秒开率仍保持 90% 以上。

**兼容性**：卡槽 300 / 436 两档全量适配；真机字体膨胀场景行高 px 锁定 + ≥ 10% 冗余；音频频段按手机扬声器外放调优。

**可用性（降级设计）**：音频失败静默降级；上报失败不阻塞交互；回读失败时卡内本地态可玩。核心体验（捏压 + 视觉反馈）不依赖任何网络请求成功。

**安全性**：无硬编码密钥，凭据运行时注入；不申请敏感权限；采集内容仅限解压统计本身，不含个人敏感信息；音效与背景音乐资源经 request 域名白名单加载。

**打扰边界**：遵循系统静音开关；无推送、无弹窗。

## 八、验收标准

**功能验收：**

- 长按 → 档位反馈 → 捏爆 → 解压值入账，全链路无卡死、无错档；「再捏一次」复原蜡皮且统计不重置；
- DIY：装饰件（蝴蝶结、耳朵等）超出球体轮廓不被裁剪——双层结构，外层承载装饰不做裁剪、内层球壳负责材质与爆浆的球形呈现，两层同步形变；预览即所得；
- 叠捏 100 只：不卡顿、无音频风暴（抽样生效）、解压值按倍率正确入账；
- 切香皂：6 刀闭环，刀扫过、皂屑散落、皂片留存三类动画清晰可见，评分出现，换新清空；
- 状态互通：连续执行「卡片捏压 → 进落地页 → 返回卡片」三轮，累计解压值零丢失。

**体验验收：**

- 300 与 436 两档槽高下核心内容可读、无重叠、无裁边；
- 秒开率 ≥ 90% 且 LCP P99 ≤ 1.5s，连续两个自然日满足；
- 三档音效盲听可区分，外放不被背景音乐掩蔽。内部盲听评分 ≥ 9/10（捏爆音效 9.0、切皂音效 9.4 实测通过）。

**数据验收：**

- 400ms 节流生效（高频捏压下上报次数受控）；隐藏/卸载瞬间兜底上报可复现；跨端数值一致（同互通用例）。

**质量验收：**

- 峰值日能力调用失败影响设备占比 ≤ 1%（11-25 实测 3,021 台 / 0.7%，达标）；
- 已登记 6 组 JS 异常完成治理，或逐组确认无用户可见影响后关闭。

**遗留验收项（待办）**：落地页音效域名白名单配置（依赖平台配置工具恢复）→ 配置后真机复验音效播放；该项未完成前，真机切皂静音不判为验收失败。

## 九、数据埋点

**口径总则：**

- 运行数据由平台自动采集（只读）：PV / UV、秒开率、LCP、JS 异常、能力调用失败。UV 按设备去重、按自然日 T+1 汇总，跨日不可累加；
- 业务账本由服务端累计并回读：累计解压值、捏捏次数、最高力度。账本数据走兜底上报，不允许丢；
- 行为埋点允许丢失：埋点失败即丢弃、不重试、不阻塞主流程——与账本的容忍度刻意不同。

**业务事件规划：**

| 事件 | 触发时机 | 关键参数 | 用途 |
| --- | --- | --- | --- |
| squeeze_start | 手指按下球体 | 玩具 ID、叠捏数量 | 有效按压发起 |
| squeeze_release | 松手（含未捏爆） | 最大力度值、按压时长 | 力度分布、放弃点分析 |
| burst | 触发捏爆 | 玩具 ID、力度档、叠捏数量 | 捏爆达成率 |
| diy_apply | DIY 确认生效 | 预设/拼装组合、颜色、内馅 | 自定义偏好 |
| stack_change | 叠捏数量调整 | 调整前后数量 | 数量偏好与上限触达 |
| landing_enter | 进入落地页 | 进入时累计解压值 | 卡 → 页转化 |
| game_enter / game_complete | 小游戏进入 / 完成 | 游戏类型、成绩（如切面评分） | 玩法矩阵分流 |
| rematch | 点击「再捏一次」 | — | 复玩意愿 |

**统计规则补充**：解压值口径按 R5；等级按累计值实时落档；捏捏次数按产生力度反馈的有效捏压计。

## 十、其他说明

**消息通知**：不做推送、不做弹窗。回访动机交给等级成长与解压值积累，不靠外唤——解压场景最忌被产品打扰。

**系统依赖**：平台兴趣卡容器与宿主能力（落地页入口、背景音乐播放、分发）；内容分发网络（音效/背景音乐资源，request 域名白名单）；服务端统计与回读接口；云数据库（累计账本）。

**资产来源**：音效为按真实材料声学结构合成的自制资产（蜡壳脆裂、皂屑崩落均为合成制作，非搬运采样）；背景音乐采用平台曲库授权资产。

**已知遗留**：

1. 落地页音效域名白名单待平台配置工具恢复后补配，并做真机复验（不影响玩法与视觉）；
2. 线上 6 组 JS 异常在治理中；
3. 收藏、分享等抖音侧互动数据在创作者后台查看，本文档数据口径不包含。

**协作模式**：本产品由个人以「产品定义 + AI 协作开发」方式完成。需求、规则与验收以本文档为基线，20+ 轮迭代均按「澄清 → 生成 → 浏览器验收 → 真机复盘」闭环推进；规则变更先改本文档、再动实现。
