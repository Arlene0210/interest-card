# DESIGN.md — 脆皮捏捏解压馆

Surface: both
任务与核心交互：轻量解压小游戏「脆皮捏捏」。用户在兴趣卡上长按捏瘪一只软萌捏捏玩具，按得越久捏得越瘪，松手后形状保持凹陷不回弹，伴随捏压音效与正向反馈文案；进入兴趣卡落地页后承接本次游玩的解压报告，并提供多款同类型解压小游戏的快速入口（捏泡泡纸 / 疯狂解压按钮 / 切香皂）供切换体验。

---

## OpenCard（兴趣卡）

Layout: 无（无匹配已收录 Layout，按 widget 最小骨架扩展）
Components: 仅白名单原语（View / Text），玩具主体与捏痕由 CSS 渐变 + 状态 class 表达，不使用图片资源
分区：Header（无，宿主已展示业务标题，不重复）/ Body / Footer（切换捏捏 + 换新一个的真实卡内动作）

### Body 信息组织

- 玩法提示行（caption）：`长按捏瘪它 · 按得越久捏得越瘪`
- 捏捏玩具主体（adaptive）：单只大号捏捏球，CSS 圆形 + 高光 + 底部捏痕层；按住时随力度压扁（scaleY 收缩、宽度微涨、捏痕加深），松手后停在压扁态不回弹；捏瘪度满 100% 呈「捏爆」态并提示换新
- 反馈区：按住时显示力度条与拟声词（按玩具音效文案）；松手后显示本次反馈文案与「解压值 +N」飘字，1.6s 后淡出；解压值累计常驻显示
- 状态：Loading / Empty / Error 复用同一 Body（文案 + 重试），保留底板

### Footer

- 玩具切换：3 个迷你圆点按钮（当前款高亮），点击切换捏捏并重置当前捏瘪度
- 「换一个捏捏」按钮：仅在当前捏瘪度 ≥ 60% 时高亮可用，点击重置当前玩具；未达阈值时置灰但保留宽度

### 变体与状态

- 默认：满弹性捏捏球，提示行 + 累计解压值
- 按住中：力度条增长、球体随力度形变、拟声词气泡
- 松手后：保持形变、反馈文案 + 飘字、解压值更新
- 捏爆态：球体压至最扁、出现爆裂拟声词、Footer「换一个捏捏」高亮
- Loading / Error：Body 内文案切换，Error 提供重试

### 状态信息

- 当前任务：捏瘪当前捏捏玩具
- 即时反馈：形变动画、拟声词、力度条、解压值
- 延后到落地页：解压报告详情、其他小游戏

### 交互（区域 | 动作 | 可见反馈）

| 区域 | 动作 | 反馈 |
| --- | --- | --- |
| 玩具主体 | 按住（onTouchStart，力度随按住时长增长） | 球体随力度压扁、力度条增长、拟声词气泡 |
| 玩具主体 | 松手（onTouchEnd） | 保持凹陷不回弹、播放捏压音效、解压值飘字、按力度档位给反馈文案 |
| Footer 圆点 | 点击切换玩具 | 切换主体颜色/软度/音效、重置捏瘪度、当前款高亮 |
| Footer 换新 | 点击「换一个捏捏」 | 当前玩具回弹到全新状态 |

### 空间与字阶

- 正文与操作优先；玩具主体为 adaptive 区域，300 槽高下保持球体直径约 42vh、436 槽高下放大且不溢出
- 字号：提示行 caption（0.75rem）、反馈文案 status-message（1rem）、解压值数值 metric 缩小版（1.25rem bold）
- 不纵向滚动、无 `@media`；Header/Footer 无内容时不渲染

### 适配方案

- 保留壳层 `.widget-root` / `.widget-body` / FMP 标注结构；业务 class 全部重新命名（`squishy-*` 前缀）
- 玩具球体：多层 box-shadow + radial-gradient 高光，捏痕用底部椭圆 shadow 加深表达；形变只用 transform / opacity（Lynx 动画优先项）
- 主题色：奶油白 + 薄荷 + 奶黄三款玩具色（#ffe6d8 / #cef3e2 / #fff0c6），底板保持模板 token（白色 8% 半透明）

### 背景

- `PrimaryColor`：取拼接脚本输出 `#514f48`
- `BgMusicUrl`：由宿主播放，卡代码不实现背景音

## MicroApp（兴趣卡落地页）

风格：现代产品 UI，浅色奶油马卡龙主题（与卡片同调性），背景 `#fff9f4` 暖奶油白，文字 `#16181f`（dark.950），单一强调色软粉 `#ff8fab`，辅助薄荷 `#3fae7a`。层级：字阶 → 留白 → 对齐 → 底色 → Card。

页面结构（3 页 + 卡片承接首屏）：

1. `pages/index/index` 首屏「解压报告 + 小游戏馆」
   - 首屏背景关系：导航避让区、报告标题区与内容区共享同一奶油底色视觉面，用 `<CustomNavSpace />` 几何避让，不拆分高对比头部
   - 解压报告卡（承接卡内状态）：本次捏捏次数、最高力度档、累计解压值；数据来自服务端按用户维度的最近一次游玩记录；无记录时展示引导空态「去信息流捏一捏，回来看报告」，不伪造数据
   - 报告下方「解压小游戏馆」标题 + 3 款游戏入口列表（每款一张浅底圆角条目：名称、一句话说明、图标 emoji、进入箭头），点击进入对应游戏页
   - 底部小字：回到信息流可以再捏一捏
2. `pages/bubble/index` 捏泡泡纸：6×8 泡泡网格，点击捏爆（凹陷 + 波纹态 class），全部捏完显示「本片解压度 100%」与「再来一片」重置；顶部显示已捏数量
3. `pages/button/index` 疯狂解压按钮：大按钮连点充能（每次点击 +进度），满格触发全屏彩带 emoji 飘落与「解压能量爆发」提示，随后自动清零可再充；顶部显示累计按压次数
4. `pages/soap/index` 切香皂：一块香皂（圆角色块），点击「切一刀」掉落一片碎屑（切掉比例 +1，色块变薄），切完显示切面评分与「换一块」重置；香皂颜色随机从主题色系取

与兴趣卡共享的主题和组件：

- 主题色与卡内玩具色系一致（奶油 / 薄荷 / 奶黄 / 软粉）；标题字阶、圆角、间距沿用 system token（rem）
- 落地页使用 Tailwind 类实现样式；按钮等表单控件从 SDK UI 库导入，禁止从 `@tarojs/components` 导入 Button/Input
- 主列表用 View 自然滚动，不用 ScrollView
- 卡片 → 落地页状态衔接：卡内松手完成一次捏压后上报服务端（mutation）；落地页首屏每次显示（useDidShow）拉取最新报告并展示，保证「卡上捏、页内看」状态互通，不要求用户重复操作
