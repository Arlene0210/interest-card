# DESIGN.md — 脆皮捏捏解压馆

Surface: both
任务与核心交互：轻量解压小游戏「脆皮捏捏」。用户在兴趣卡上长按捏瘪一只软萌捏捏玩具，按得越久捏得越瘪，松手后形状保持凹陷不回弹，伴随捏压音效与正向反馈文案；支持卡内 DIY 拼装形象工坊（卡通形象预设 + 身体/耳朵/配色/内馅自由组合）、底部加减号实时控制 1-100 只叠捏（侧视堆叠成塔、音效更脆更密）、捏爆瞬间泛白蜡皮崩裂露出内馅的真实动效（蜡皮片状碎裂掉落、内馅涌出、变形凹陷）；进入兴趣卡落地页后承接本次游玩的解压报告，并提供多款同类型解压小游戏的快速入口（捏泡泡纸 / 疯狂解压按钮 / 切香皂）供切换体验。

## 迭代 v4：蜡皮材质 + 侧视堆叠 + 加减控制（对照真实蜡皮捏捏参考图）

真实蜡皮捏捏参考图的关键特征：①蜡皮是泛白/浅色的脆壳（奶白、浅蜜桃、浅蓝灰、暖橙等），表面半哑光微光泽；②捏爆时蜡皮片状碎裂——大片撕裂 + 条状碎片 + 三角缺口，边缘卷曲翘起，部分碎片仍粘附、部分掉落；③裂开后露出内馅（黏稠、湿润高光、拉丝），内馅颜色与蜡皮形成对比；④捏爆后形状不规则——中心塌陷、边缘碎片隆起、局部鼓包，不是均匀压扁。

### 蜡皮材质（球体外观重做）

- 球体底色改为「泛白蜡皮」：由玩具主色向白色混合约 65%（JS 计算蜡皮色），叠加主色 radial 晕染层（`.squishy-tint`，opacity 约 0.45），保留高光与内阴影，整体呈「半哑光蜡壳」观感
- 耳朵/头顶装饰保持玩具主色（彩色蜡皮装饰件），与泛白壳身形成层次
- 蜡皮碎片颜色 = 蜡皮色（非主体色），体现「蜡皮被捏碎」而非「球体炸开」

### 捏爆过程（蜡皮碎裂露馅）

- **裂口露馅**：捏爆瞬间内馅芯从蜡皮裂口涌出——馅芯放大至约 2.2 倍并常驻于球心（馅色 = 玩具内馅色），形成「泛白蜡皮破了、里面馅露出来」的核心画面
- **蜡皮碎片**：12 片蜡皮碎块（蜡皮色、片状带卷边阴影）从球缘炸出，另增 3 片向下坠落的掉屑（重力感，视频特征：蜡皮破碎并有些许掉落）
- **翻皮**：裂口两片蜡皮向上外翻翘起（v3 已有，颜色改为蜡皮色）
- **浆液**：浆帽 + 挂壁拉丝保持 v3 规格（颜色 = 内馅色）

### 捏爆后形状（变形 + 凹陷）

- 爆裂中：压塌 scaleY 0.3 / scaleX 1.42 + **不规则变形 border-radius**（如 52% 48% 55% 45% / 62% 38% 58% 42%），避免均匀压扁的呆板感
- 爆后残体（burstShaped 态）：保持压扁（scaleY 约 0.55）+ 不规则圆角 + 馅芯常驻（opacity 0.85）+ 凹陷捏痕常驻，呈现「捏爆后破相的软团」；换新或 DIY 应用后恢复全新蜡皮
- 轻捏/用力捏的凹陷态沿用 v3（dent 逐级显现、松手不回弹）

### 压力等级（按解压值分档）

- 三档力度档位升级为「压力等级」：服务端下发 label 为 `Lv.1 轻捏`（解压 +5）/ `Lv.2 用力捏`（解压 +10）/ `Lv.3 捏爆`（解压 +20）
- 力度条标签显示当前压力等级；反馈文案与解压值飘字保持；统计行「最高压力等级」承接最高档

### 侧视堆叠（替代蜂窝摊开）

- 叠捏从「蜂窝平面摊开」改为**垂直堆叠成塔的侧视图**：每只捏捏渲染为压扁椭圆（侧视截面），从下往上叠放，底部对齐、整体垂直居中
- 每只带轻微横向错位（正弦抖动 ±4%）与自然层叠感；耳朵只影响顶层可见性（被上层球自然遮挡）
- 单只尺寸随数量收缩：≤3 只约 36% 宽完整椭圆、≤10 只 32%、≤25 只 26%、≤50 只 20%、51-100 只 15%；层间距按数量压缩（重叠堆叠），100 只时呈「薄层塔」仍不超出玩区
- 堆叠为纯视觉层叠（z-index 按 index），整摞同步按压形变与捏爆动画（爆裂元素锚定塔中心 = 容器中心）

### 数量控制：加减号实时步进（替代 ×1/×3/×5 快捷档）

- 移除右侧快捷档按钮组；在玩区底部新增水平控制条：`[−] 数字输入 [+ ]`
- `−` / `+` 圆形按钮点击步进 ±1，**长按 500ms 后每 120ms 连续 ±5**（松手停止），实时重排堆叠塔
- 数字输入框保留（type=number，1-100，越界钳制并高亮提示）；数量变化即时生效，无需确认

### 服务端配置同步

- `stack` 载荷移除 `quickOptions`，保留 `customLabel`（"数量"）/ `min` / `max`
- `levels` label 带 Lv 前缀（压力等级）

### 音效（不变）

- 沿用 v3：单只轻捏 1 次脆响、用力捏 2 连脆响、捏爆「先脆后闷」双段；叠捏按只数连播（间隔约 40-90ms、速率缓升封顶 2.2 倍速），数量 > 12 按比例抽样

### 变体与状态（v4 追加）

- 数量步进态：`−`/`+` 按下有按压态；到边界（1 / 100）时对应按钮置灰、输入框高亮提示
- 捏爆残体态：爆裂动画结束后球体保持「破相」形状（变形圆角 + 馅芯外露），Footer 换新按钮高亮
- 堆叠布局：1 只完整椭圆居中；多只垂直叠塔侧视；100 只薄层塔
- Loading / Error 不变

## 迭代 v3：形象工坊 + 真实爆浆（历史，部分被 v4 替代）

## OpenCard（兴趣卡）

Layout: 无（无匹配已收录 Layout，按 widget 最小骨架扩展）
Components: 仅白名单原语（View / Text），玩具主体与捏痕由 CSS 渐变 + 状态 class 表达，不使用图片资源
分区：Header（无，宿主已展示业务标题，不重复）/ Body / Footer（切换捏捏 + 换新一个的真实卡内动作）

### Body 信息组织

- 玩法提示行（caption）：`长按捏瘪它 · 按得越久捏得越瘪`
- 捏捏玩具主体（adaptive）：单只大号捏捏球，CSS 圆形 + 高光 + 底部捏痕层；按住时随力度压扁（scaleY 收缩、宽度微涨、捏痕加深），松手后停在压扁态不回弹；捏瘪度满 100% 呈「捏爆」态并提示换新
- 反馈区：按住时显示力度条与拟声词（按玩具音效文案）；松手后显示本次反馈文案与「解压值 +N」飘字，1.6s 后淡出；解压值累计常驻显示
- 状态：Loading / Empty / Error 复用同一 Body（文案 + 重试），保留底板

### Footer

- 玩具切换：3 个迷你圆点按钮（当前款高亮），点击切换捏捏并重置当前捏瘪度
- 「换一个捏捏」按钮：仅在当前捏瘪度 ≥ 60% 时高亮可用，点击重置当前玩具；未达阈值时置灰但保留宽度

### 变体与状态

- 默认：满弹性捏捏球，提示行 + 累计解压值
- 按住中：力度条增长、球体随力度形变、拟声词气泡
- 松手后：保持形变、反馈文案 + 飘字、解压值更新
- 捏爆态：球体压至最扁、出现爆裂拟声词、Footer「换一个捏捏」高亮
- Loading / Error：Body 内文案切换，Error 提供重试

### 状态信息

- 当前任务：捏瘪当前捏捏玩具
- 即时反馈：形变动画、拟声词、力度条、解压值
- 延后到落地页：解压报告详情、其他小游戏

### 交互（区域 | 动作 | 可见反馈）

| 区域 | 动作 | 反馈 |
| --- | --- | --- |
| 玩具主体 | 按住（onTouchStart，力度随按住时长增长） | 球体随力度压扁、力度条增长、拟声词气泡 |
| 玩具主体 | 松手（onTouchEnd） | 保持凹陷不回弹、播放捏压音效、解压值飘字、按力度档位给反馈文案 |
| Footer 圆点 | 点击切换玩具 | 切换主体颜色/软度/音效、重置捏瘪度、当前款高亮 |
| Footer 换新 | 点击「换一个捏捏」 | 当前玩具回弹到全新状态 |

### 空间与字阶

- 正文与操作优先；玩具主体为 adaptive 区域，300 槽高下保持球体直径约 42vh、436 槽高下放大且不溢出
- 字号：提示行 caption（0.75rem）、反馈文案 status-message（1rem）、解压值数值 metric 缩小版（1.25rem bold）
- 不纵向滚动、无 `@media`；Header/Footer 无内容时不渲染

## MicroApp（兴趣卡落地页）

风格：现代产品 UI，浅色奶油马卡龙主题（与卡片同调性），背景 `#fff9f4` 暖奶油白，文字 `#16181f`（dark.950），单一强调色软粉 `#ff8fab`，辅助薄荷 `#3fae7a`。层级：字阶 → 留白 → 对齐 → 底色 → Card。

页面结构（3 页 + 卡片承接首屏）：

1. `pages/index/index` 首屏「解压报告 + 小游戏馆」
   - 首屏背景关系：导航避让区、报告标题区与内容区共享同一奶油底色视觉面，用 `<CustomNavSpace />` 几何避让，不拆分高对比头部
   - 解压报告卡（承接卡内状态）：本次捏捏次数、最高力度档、累计解压值；数据来自服务端按用户维度的最近一次游玩记录；无记录时展示引导空态「去信息流捏一捏，回来看报告」，不伪造数据
   - 报告下方「解压小游戏馆」标题 + 3 款游戏入口列表（每款一张浅底圆角条目：名称、一句话说明、图标 emoji、进入箭头），点击进入对应游戏页
   - 底部小字：回到信息流可以再捏一捏
2. `pages/bubble/index` 捏泡泡纸：6×8 泡泡网格，点击捏爆（凹陷 + 波纹态 class），全部捏完显示「本片解压度 100%」与「再来一片」重置；顶部显示已捏数量
3. `pages/button/index` 疯狂解压按钮：大按钮连点充能（每次点击 +进度），满格触发全屏彩带 emoji 飘落与「解压能量爆发」提示，随后自动清零可再充；顶部显示累计按压次数
4. `pages/soap/index` 切香皂：一块香皂（圆角色块），点击「切一刀」掉落一片碎屑（切掉比例 +1，色块变薄），切完显示切面评分与「换一块」重置；香皂颜色随机从主题色系取

与兴趣卡共享的主题和组件：

- 主题色与卡内玩具色系一致（奶油 / 薄荷 / 奶黄 / 软粉）；标题字阶、圆角、间距沿用 system token（rem）
- 落地页使用 Tailwind 类实现样式；按钮等表单控件从 SDK UI 库导入，禁止从 `@tarojs/components` 导入 Button/Input
- 主列表用 View 自然滚动，不用 ScrollView
- 卡片 → 落地页状态衔接：卡内松手完成一次捏压后上报服务端（mutation）；落地页首屏每次显示（useDidShow）拉取最新报告并展示，保证「卡上捏、页内看」状态互通，不要求用户重复操作
