# DESIGN.md — 脆皮捏捏解压馆

Surface: both
任务与核心交互：轻量解压小游戏「脆皮捏捏」。用户在兴趣卡上长按捏瘪一只软萌捏捏玩具，按得越久捏得越深（粘土局部凹陷 + 白蜡粉霜壳 + 蜡皮裂纹渐现 + 裂缝渗馅），松手后指印保持不回弹（陶土记忆），伴随三源真实音效（蜡皮脆裂 / 崩壳 / 粘土湿陷）与正向反馈文案；支持卡内 DIY 拼装形象工坊（卡通形象预设 + 身体/耳朵/配色/内馅自由组合）、底部加减号实时控制 1-100 只叠捏（侧视堆叠成塔、音效更脆更密）、捏爆瞬间泛白蜡皮崩裂露出内馅的真实动效（蜡皮片状碎裂掉落、内馅涌出、变形凹陷）；进入兴趣卡落地页后承接本次游玩的解压报告（压力等级 + 俏皮解释 + 解压建议），并提供多款同类型解压小游戏的快速入口（捏泡泡纸 / 疯狂解压按钮 / 切香皂）供切换体验。

## 迭代 v7：真实材质三源音效 + 白蜡粉霜层 + 粘土局部凹陷 + 深捏加重（对照真实脆皮捏捏材料工艺）

- **三源音效（已实施并试听）**：按脆皮捏捏乐材料声学特征用 numpy 合成三段采样（脚本 `/workspace/tmp/synth-sfx.py`），上传 CDN 后经 `createInnerAudioContext` 播放：
  - `wax-crack`（蜡皮单次脆裂）：大豆蜡脆壳的断裂基频 + 高频咔哒瞬态，对应 68℃ 大豆蜡「脆而不硬」+ 蜂蜡韧性 —— 跨过 35% 力度播一声低配版、跨过 60% 播高配版（按压中实时闩锁，一次按压各播一次）
  - `wax-burst`（捏爆崩壳）：更重的断裂 + 密集碎屑（石蜡+蜂蜡 9:1 的脆感）；捏爆时主音，0.22s 后接大口湿陷
  - `clay-squish`（粘土内馅湿陷）：时变低通 + 低频肉感 200Hz + 湿滑黏扯 + 珍珠岩细颗粒沙沙 + 气泡破音（对应超轻粘土+纸黏土+甘油的内馅材料、珍珠岩颗粒填充）—— 轻捏/起手/用力捏/捏爆各档均以它为底层湿陷声
  - 分层组合：轻捏=纯湿陷；用力捏=脆裂+85ms 后湿陷；捏爆=崩壳+220ms 后大口湿陷；叠捏按只数密集连播（rate 递增）
- **白蜡粉霜层（已实施）**：在蜡膜（`squishy-wax-film`，乳白半透壳）之上新增 `squishy-wax-frost`——细小白点轻覆表面（radial-gradient 四点），模拟大豆蜡冷凝后的哑光霜感；蜡膜本体加厚（渐变加深 + 底部补一团暖白），任何颜色玩具外都罩乳白蜡壳；DIY 预览同步挂霜层
- **粘土局部凹陷（已实施）**：按压几何改为「局部凹陷为主，整体只轻微紧绷」——按压中 `scaleY` 最多 -10%、松手 `scaleY 0.97` 近圆，绝不整球压扁；凹陷组（`squishy-dent-group`）= 深色凹坑（`dent-pit`）+ 坑口上缘受光弧（`dent-edge`）+ 下缘亮色隆起唇（`dent-rim`），松手后按峰值保留（陶土指印，`dentSettled`）；三处次级压痕随力度依次显现
- **深捏加重（已实施）**：≥75% 力度起凹坑额外扩大（scale 峰值 1.48）并切换 `is-deep` 态——坑底更黑更集中（radial-gradient 中心 rgba(40,18,4,0.97)）、坑口阴影加深；裂纹透明度上限提到 0.95
- **裂纹加粗 + 分叉（已实施）**：主裂纹加粗至 5.5px、色深提至近黑棕、加双 shadow（上亮边+下深影）；新增 2 条分叉细屑（crack-7/8）与主裂缝形成不规则分叉感；渗馅泉眼 z-index 提至 5（盖在裂缝线之上）且锚点按裂缝线心重新对位（馅从裂口冒出）；泉眼加大（30%×21%）加湿感阴影
- **残体毛边（已实施）**：主裂口线加粗、新增 3 处锯齿毛边（`remnant-cleft-nick`）；翻皮加大加厚（加 inset 描边层）；碎屑扩为 7 片（混蜡皮色/馅色/壳色三色、大小错落更随机）

  - **泵浆柱**（3 根主裂缝）：多段果冻式生长后大幅瘫软倒伏贴面（rotate 至 62-76deg、scaleY 0.5、scaleX 拉宽），倒伏末段幅度加强；时长 1.5s + 最迟延迟 0.3s < BURST_MS 1950ms 不截断
  - **浆滴**：挂壁拉丝下坠（拉长变细）+ 斜飞迸溅 + 边缘溢流；白闪延长至 0.3s 四段脉冲（截图更易捕捉且不遮盖碎裂）
  - **时序验证**（150/300/500/800/1200/1700ms 逐帧）：先碎裂后爆浆时序成立；碎裂期碎片飞散、裂纹清晰、球体塌陷；涌出期三柱错峰生长、泉眼渗出、中心馅团鼓出；末段横向堆积与垂挂拉丝到位，馅色占比克制不铺满

## 迭代 v5：书桌场景 + 双手捏合 + 裂缝泵浆（对照用户反馈）

- **书桌场景背景**：玩区改为「卧室书桌一角」纯 CSS 场景——暖色墙面（上半）+ 台灯暖光晕 + 木桌面（下 40%，带桌沿高光线）+ 左上小盆栽（三叶 + 陶盆）+ 右侧书堆（三本错落）三件低饱和摆件；场景面板自带圆角裁切，玩区本体不裁切（碎片飞行不被切断）

## 迭代 v4.1：爆浆节奏与视图规则修正（对照用户反馈）

- **单只正视图**：数量 1 时以近圆大球（52% 宽）完整展示形象；>1 才切换为侧视压扁椭圆堆叠塔

## 迭代 v4：蜡皮材质 + 侧视堆叠 + 加减控制（对照真实蜡皮捏捏参考图）

真实蜡皮捏捏参考图的关键特征：①蜡皮是泛白/浅色的脆壳（奶白、浅蜜桃、浅蓝灰、暖橙等），表面半哑光微光泽；②捏爆时蜡皮片状碎裂——大片撕裂 + 条状碎片 + 三角缺口，边缘卷曲翘起，部分碎片仍粘附、部分掉落；③裂开后露出内馅（黏稠、湿润高光、拉丝），内馅颜色与蜡皮形成对比；④捏爆后形状不规则——中心塌陷、边缘碎片隆起、局部鼓包，不是均匀压扁。

### 蜡皮材质（球体外观重做）

- 球体底色改为「泛白蜡皮」：由玩具主色向白色混合约 65%（JS 计算蜡皮色），叠加主色 radial 晕染层（`.squishy-tint`，opacity 约 0.45），保留高光与内阴影，整体呈「半哑光蜡壳」观感
- 耳朵/头顶装饰保持玩具主色（彩色蜡皮装饰件），与泛白壳身形成层次
- 蜡皮碎片颜色 = 蜡皮色（非主体色），体现「蜡皮被捏碎」而非「球体炸开」

### 捏爆过程（蜡皮碎裂露馅，先碎裂后爆浆两段时序）

- **两段时序（对照真实视频）**：捏爆瞬间先呈现「蜡皮碎裂」——白闪短促一闪（0-0.16s，不遮盖碎裂）+ 12 片蜡皮碎块从球缘炸出（0-0.95s）+ 3 片掉屑下坠 + 裂口两片翻皮上翘，壳体开始塌陷；0.32s 起「馅料爆出」——内馅芯从破口涌出（透明度 0 → 0.92、scale 1 → 2 渐显过渡）、浆帽鼓包、挂壁拉丝与四溅浆点随后跟上；内馅用不规则 ooze 圆角，铺至破口边缘但保留蜡皮残边，不是均匀色块替换
- **平时不露馅**：内馅芯常驻挂载但捏爆前完全透明（蜡皮未破看不到馅），轻捏/用力捏态只显捏痕与裂纹（≥60% 力度浮现裂纹），消除「馅色铺满」的错观
- **蜡皮碎片**：12 片蜡皮碎块（蜡皮色、片状带卷边阴影）从球缘炸出，另增 3 片向下坠落的掉屑（重力感，视频特征：蜡皮破碎并有些许掉落）
- **翻皮**：裂口两片蜡皮向上外翻翘起（v3 已有，颜色改为蜡皮色）
- **浆液**：浆帽 + 挂壁拉丝保持 v3 规格（颜色 = 内馅色），整体延迟 0.32s 让碎裂过程先可见

### 捏爆后形状（变形 + 凹陷，单调塌陷不回弹）

- 塌陷曲线单调递减：按压满力 scaleY 0.7 → 爆裂中 scaleY 0.46（0.42s 塌陷过渡，馅料随爆出流失壳体随之瘪掉）→ 残体 scaleY 0.42，**绝不向上回弹**（爆裂中/残体各自使用无过冲的 cubic-bezier）；宽度 1.14 → 1.26 → 1.3 单调外扩
- 爆裂中：不规则变形 border-radius（52% 48% 55% 45% / 62% 38% 58% 42%）；爆后残体（burstShaped 态）保持更歪扭的圆角 + 内馅芯偏心常驻（opacity 0.85）+ 主裂口翻边 + 凹陷捏痕，呈现「捏爆后破相的软团」；换新或 DIY 应用后恢复全新蜡皮
- 轻捏/用力捏的凹陷态沿用 v3（dent 逐级显现、松手不回弹）

### 压力等级（按解压值分档）

4. `pages/soap/index` 切香皂：一块香皂（圆角色块），点击「切一刀」掉落一片碎屑（切掉比例 +1，色块变薄），切完显示切面评分与「换一块」重置；香皂颜色随机从主题色系取

与兴趣卡共享的主题和组件：

- 主题色与卡内玩具色系一致（奶油 / 薄荷 / 奶黄 / 软粉）；标题字阶、圆角、间距沿用 system token（rem）
- 落地页使用 Tailwind 类实现样式；按钮等表单控件从 SDK UI 库导入，禁止从 `@tarojs/components` 导入 Button/Input
- 主列表用 View 自然滚动，不用 ScrollView
- 卡片 → 落地页状态衔接：卡内松手完成一次捏压后上报服务端（mutation）；落地页首屏每次显示（useDidShow）拉取最新报告并展示，保证「卡上捏、页内看」状态互通，不要求用户重复操作
